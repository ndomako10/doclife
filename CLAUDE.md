# Project Instructions: doclife

These add to the global CLAUDE.md. Global instructions apply except where
noted.

## What this repo is

A Python package that checks document frontmatter in git repos, stamps
modified dates and reports documents due for review. Extracted from
rwk-auto-bot's `tools/docs_check.py`, decided in domako-tech's ADR-009.
Public on GitHub (`ndomako10/doclife`), released to PyPI.

## Public repo

Everything here, including commit messages, issues and test fixtures, is
public.

- Test fixtures are invented documents. Never copy a real document from
  another repo into a test.
- Nothing from domako-tech's private or employer list, and no customer or
  business details from any repo.
- Commits use the GitHub noreply address, set in this repo's git config.
  The global git email is personal and must not be used here.

## Process

- **Issues:** GitHub Issues via `gh`.
- **Code:** TDD with BDD-style test names. No runtime dependencies; the
  standard library only, so installing it adds nothing to a repo's supply
  chain.
- **Toolchain:** `requirements-dev.txt` is hash-locked and compiled by uv;
  CI installs with `--require-hashes`. Actions are pinned by commit SHA.
- **ADRs:** `docs/ADRs/ADR-NNN-*.md` with the vault frontmatter; this repo
  is indexed by `local-ai-tools`.
- **Changelog:** generated by git-cliff (`cliff.toml`) before each release.
- **Versioning:** semantic. The settings file format and the frontmatter
  fields are the public interface; changing either is a major version once
  1.0 is out.
